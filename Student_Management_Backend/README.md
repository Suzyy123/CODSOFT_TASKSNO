A backend REST API built with Node.js, Express.js, MySQL, and Sequelize ORM for managing students, courses, and student enrollments.

Technologies Used
Node.js — JavaScript runtime used to run the backend outside the browser.
Express.js — Web framework used to create the server and API routes.
MySQL — Relational database used to store students, courses, and enrollments.
Sequelize — ORM used to communicate with MySQL using JavaScript instead of writing SQL for every database operation.
Postman — Used to test the API endpoints.
dotenv — Used to load database and server configuration from environment variables.
Nodemon — Automatically restarts the server when code changes during development.
